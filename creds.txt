Setup Instructions:

1. Install prerequisites
- Node.js 20.19+ for the frontend build
- Docker Desktop
- npm

2. Create environment files
- Copy `server/.env.example` to `server/.env`
- Copy `client/.env.example` to `client/.env`
- Fill in the server secrets, database values, and Cloudinary credentials

3. Start local services
```bash
docker compose up -d mysql phpmyadmin
```

4. Install dependencies
```bash
cd server
npm install
cd ../client
npm install 
```

5. Run migrations and seeds
```bash
cd server
npm run setup
```

6. Start the backend
```bash
cd server
node index.js
```

7. Start the frontend
```bash
cd client
npm run dev
```

Useful local URLs:
- Frontend: `http://localhost:5173`
- Backend: `http://localhost:5000`
- MySQL: `localhost:3310`
- phpMyAdmin: `http://localhost:8081`

Notes:

- For Vercel + Railway, set `VITE_API_URL` to the Railway backend URL.
- For production auth, use `AUTH_COOKIE_SAME_SITE=none` and `AUTH_COOKIE_SECURE=true`.
